# ML service — not implemented in V0.1.0
There is intentionally no model, prediction endpoint, or hard-coded risk score in this release.

Before connecting a model, verify and document its exact artifact/version, data provenance, label definition, preprocessing and units, missing-data policy, held-out evaluation and calibration, subgroup performance, limitations, qualified expert review, API schema, timeout behavior, and safe failure mode.

Until then, this repository is a research scaffold only—not a diagnostic or clinical decision tool.
